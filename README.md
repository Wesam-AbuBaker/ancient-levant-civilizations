# انهيار حضارات الشام القديمة — HTML5

الصف: السابع/د — المادة: دراسات اجتماعية — المعلم: أسامة محمد إبراهيم الغويري.

عرض مستقل من 14 شريحة، باستخدام الصور الأصلية المضمنة في PowerPoint. لا توجد في المصدر وسائط فيديو أو روابط خارجية، ولذلك لم تُضف أزرار لها.

## الاستخدام
افتح `index.html` من Chrome، أو ارفع محتويات هذا المجلد (وليس المجلد نفسه) إلى جذر مستودع GitHub Pages.

## التحكم
- التالي يسارًا بسهم متجه يسارًا، السابق يمينًا بسهم يمينًا.
- السحب يمينًا = الشريحة التالية، في الوضع غير المكبّر.
- التكبير بإصبعين، والتحريك بإصبع واحد عند التكبير.
- وضع ملء الشاشة يخفي الأشرطة؛ نقرة مفردة تظهر أدوات عائمة لثلاث ثوانٍ، ونقرتان للتكبير.
- Esc أو زر خروج للعودة.

## ملاحظات
الروابط/الفيديوهات غير موجودة في العرض الأصلي. لا تغيّر المحتوى التعليمي دون تدقيق المعلم.
